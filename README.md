# riassumi-preservando-linguaggio

Accorcia un testo tagliando incisi e digressioni e conserva le parole dell'autore, il loro ordine e il filo del discorso.

Fa parte della [Prompt Library di CH Labs](https://www.cryptohelvetia.com/ch-labs/prompt-library), dove la pagina di riferimento è [Riassumi preservando linguaggio](https://www.cryptohelvetia.com/ch-labs/prompt-library/skills/riassumi-preservando-linguaggio). Il repo contiene una copia della skill, rigenerata a ogni aggiornamento della libreria.

## Installare

In Claude Code aggiungi una volta il marketplace e installa il plugin.

```
/plugin marketplace add MicheDada21/ch-labs-skills
/plugin install riassumi-preservando-linguaggio@ch-labs-skills
```

Da shell i comandi sono `claude plugin marketplace add MicheDada21/ch-labs-skills` e `claude plugin install riassumi-preservando-linguaggio@ch-labs-skills`. Nell'app desktop premi + accanto al campo del prompt, apri Plugins, aggiungi il marketplace `MicheDada21/ch-labs-skills` con Add marketplace e poi il plugin con Add plugin.

Con altri agenti copia la cartella `skills/riassumi-preservando-linguaggio` tra le skill dell'agente, per esempio in `~/.codex/skills/riassumi-preservando-linguaggio`.
